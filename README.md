# Dementia Support Application

A full stack web application designed to support people living with dementia and their caregivers.  
The app helps patients remember important tasks and enables caregivers to monitor location and provide better care.

 Features
- Reminder system for daily activities
- Location tracking for dementia patients in case they go missing
- Caregiver dashboard to assist and monitor patients
- Secure user authentication
- Responsive and user-friendly interface

 Tech Stack
- Frontend: React, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Tools: Git, GitHub

 Purpose
This project addresses real-world healthcare challenges by improving safety, independence, and caregiver coordination for dementia patients.

 Installation
1. Clone the repository  
   `git clone https://github.com/yemizerfe/dementia-support-app.git`
2. Install dependencies  
   `npm install`
3. Start the development server  
   `npm run dev`
